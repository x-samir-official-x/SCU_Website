# شعار «رِواق» والأيقونات

شعار المنصة هو كلمة «رِواق» نفسها بخط عربي منساب وشريط ذهبي (الكلمة هي العلامة). يبقى ثابتًا في كل النسخ، أما شعارات الكلية والجامعة فتأتي من `config/faculty.json`. الألوان: كحلي `#102B50` وذهبي `#C9A24A`.

## الملفات

| الملف | الاستخدام |
| --- | --- |
| `public/brand/riwaq-dark.svg` | الكلمة بيضاء وذهبية على الخلفيات الغامقة (الافتتاحية، الهيرو، الدخول، القائمة الجانبية) |
| `public/brand/riwaq-light.svg` | الكلمة كحلية وذهبية على الخلفيات الفاتحة (القائمة العائمة، الاستمارة المطبوعة، ملف العرض) |
| `public/favicon.svg`, `favicon.ico`, `favicon-16.png`, `favicon-32.png` | أيقونة التبويب |
| `public/apple-touch-icon.png` (180) | أيقونة أيفون عند إضافة الموقع للشاشة الرئيسية |
| `public/icon-192.png`, `icon-512.png` | أيقونات التطبيق |
| `public/icon-maskable-512.png` | نسخة أندرويد القابلة للقص (الكلمة داخل 64% من العرض) |

الأيقونات النقطية على مربع كحلي مصمت (أيفون يحوّل الشفاف إلى أسود). الـ SVG مسار مُتتبَّع من التصميم المعتمد، وله `viewBox` ضيق بهامش صغير. لا تُعد كتابة الكلمة بخط ولا تمدّدها ولا تضف ظلًا.

## تبديل الشعار

1. استبدل `public/brand/riwaq-*.svg` مع الحفاظ على الأسماء.
2. أعد توليد الأيقونات النقطية بنفس المقاسات أعلاه.
3. غيّر `platformName` في `config/faculty.json` (يُستخدم في العنوان والـ manifest والرسائل).
4. `npm test` يتحقق من وجود الملفات والمقاسات (`tests/brand-assets.test.ts`).
